# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/mliang1604/open-rt-studio/security/advisories/new)
and not in a public issue. Include what you found, how to reproduce it, and the
affected version or commit.

Never include patient data in a report. If reproducing the problem needs a
DICOM file, describe how to generate one with `packages/testdata`.

## Scope

Open RT Studio is pre-release research software and is not for clinical use.
There are no supported release lines yet; fixes land on `main`.
